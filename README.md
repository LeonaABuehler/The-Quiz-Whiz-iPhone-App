# The Quiz Whiz - iPhone App
AI Application that allows users to generate quizzes based on uploaded PDF's and photos as a modified version of my previous website creation.


#### New Features
<ul>
  <li>Multiple Document Uploading</li>
  <li>Photo Uploading(create quizzes from photos)</li>
  <li>Play the quiz as a game.</li>
  <li>Record the quiz game to show what questions you struggled on later.</li>
  <li>Show a graph of progress based on the quiz game.</li>
  <li>Sidebar with history of previous quizzes, also with rename and delete.</li>
  <li>Button to create new quiz.</li>
</ul>
